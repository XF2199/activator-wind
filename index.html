01 / TUTORIAL

Check your Windows activation

Use Windows' own licensing tools to inspect the activation state of your installation.

01

Open Windows Terminal

Press Windows + X and open Windows Terminal or PowerShell.

02

Check activation status

For a built-in Windows check, use:

slmgr /xpr
03

Review the result

Windows will show information about the activation state of the installed edition.

04

Need a genuine license?

Open Settings → System → Activation and use the activation options provided by Windows, such as a genuine product key or digital license.

02 / COMMANDS

Windows licensing commands

Built-in Software Licensing Management Tool commands useful for inspecting your Windows license.

01

Activation status

Display whether the current Windows installation is permanently activated.

slmgr /xpr
02

License information

Display basic information about the installed Windows license.

slmgr /dli
03

Detailed information

Display more detailed licensing information from Windows.

slmgr /dlv

Windows Activation

Activation helps verify that the Windows installation is properly licensed. The activation state can be inspected from Windows Settings or built-in licensing tools.

03 / FAQ

Frequently asked questions

Is Hanzzy Activator an official Microsoft product?

No. Hanzzy Activator is an independent interface and is not affiliated with Microsoft.

Can a website execute PowerShell automatically?

A normal browser page cannot directly execute arbitrary PowerShell commands on your computer. Commands displayed here must be manually reviewed and run in your own Windows environment.

What does slmgr /xpr do?

It uses Windows' Software Licensing Management Tool to display the activation/expiration status of the installed Windows edition.

Where can I activate Windows officially?

Open Settings → System → Activation. Windows will show the available activation methods for your device.

Does this page modify Windows?

No. HTML and JavaScript running in the browser cannot directly modify your Windows licensing state.
