01 / TUTORIAL LENGKAP

Cara aktivasi Windows & Office

Ikutin step di bawah ini urut dari atas sampe bawah. Ada 2 metode: pake PowerShell (gampang) dan pake file offline (kalo metode 1 gagal).

01

Buka PowerShell sebagai Administrator

Klik Start menu, ketik PowerShell. Klik kanan di hasil pencariannya, terus pilih Run as administrator. Ini WAJIB, jangan sampe lupa.

02

Copy command MAS

Copy command di bawah ini, terus paste di PowerShell yang udah kebuka. Klik command-nya buat auto-copy.

irm https://get.activated.win | iex
03

Tekan Enter & tunggu menu muncul

Setelah paste, tekan Enter. Script bakal ke-download otomatis dan menu interaktif bakal muncul dalam beberapa detik. Sabar aja.

04

Pilih opsi aktivasi

Di menu MAS, pilih angka sesuai kebutuhan:
• [1] HWID → aktivasi Windows 10/11 permanen
• [2] Ohook → aktivasi Microsoft Office permanen
• [3] KMS38 → aktivasi Windows sampe 2038
• [4] Online KMS → aktivasi 180 hari (auto-renew)

05

Tunggu proses selesai

Script bakal ngejalanin aktivasi otomatis. Kalo udah muncul pesan sukses, tutup PowerShell dan restart komputer lu. Cek status aktivasi di Settings → System → Activation.

06

Metode cadangan: file offline

Kalo command di atas diblokir (internet/antivirus ngeyel), download file MAS_AIO.cmd dari GitHub resmi:
github.com/massgravel/Microsoft-Activation-Scripts
Klik kanan file → Run as administrator. Menu-nya sama.

⚠
Penting banget, master!

Pastiin lu ngejalanin command/download dari sumber resmi di atas. Banyak pihak jahat yang nyebar malware dengan ngerubah URL-nya. MAS ini open source, jadi kodenya bisa lu lihat sendiri.

03 / TROUBLESHOOT

Kalo ada error, cek sini

Masalah umum yang sering muncul pas aktivasi, plus solusinya.

PowerShell nggak bisa dibuka sebagai admin?

Klik kanan Start menu → pilih Windows Terminal (Admin) atau PowerShell (Admin). Kalo nggak ada opsinya, coba login pake akun administrator. Kalo masih gagal, klik Start → ketik "UAC" → set User Account Control ke default.

Command irm error / diblokir?

Biasanya karena internet provider atau antivirus blokir URL-nya. Solusinya: pake metode offline (download MAS_AIO.cmd dari GitHub), atau ganti DNS ke 1.1.1.1 / 8.8.8.8. Kalo pake antivirus, tambahin exclusion folder download-nya.

Aktivasi sukses tapi Windows masih bilang "not activated"?

Restart dulu komputernya. Kalo masih, buka PowerShell admin, jalanin slmgr /xpr buat cek status. Kalo masih gagal, ulangin proses pake MAS, pilih opsi yang beda (misal dari HWID ke KMS38).

Aktivasi Office gagal terus?

Pastiin Office-nya udah keinstall dan versinya cocok. Di menu MAS, pilih opsi Ohook. Kalo masih gagal, coba uninstall Office dulu, install ulang, baru aktivasi pake MAS.

Apakah MAS aman?

MAS open source dan kodenya bisa lu audit sendiri di GitHub. Selama lu download dari repo resmi (massgravel), harusnya aman. Jangan pernah download dari sumber nggak jelas ya, master!

04 / FAQ

Frequently asked questions

Hanzzy Activator ini produk resmi Microsoft?

Bukan. Hanzzy Activator cuma interface panduan independen, nggak berafiliasi sama Microsoft. Semua tools yang dipake (MAS, slmgr) itu pihak ketiga / built-in Windows.

Website bisa eksekusi PowerShell otomatis?

Nggak bisa. Browser biasa nggak bisa eksekusi command PowerShell secara langsung. Command di sini cuma bisa di-copy, terus lu tempel manual di PowerShell sendiri. Itu buat keamanan lu juga.

slmgr /xpr itu ngapain?

Itu pake Software Licensing Management Tool built-in Windows buat nampilin status aktivasi / kadaluarsa edisi Windows yang keinstall.

Aktivasi resmi di mana?

Buka Settings → System → Activation. Windows bakal nampilin metode aktivasi yang tersedia buat device lu (product key asli atau digital license).

Halaman ini ngubah Windows gw nggak?

Nggak. HTML dan JavaScript yang jalan di browser nggak bisa ngubah status lisensi Windows lu secara langsung. Semua eksekusi harus lu lakuin manual.
